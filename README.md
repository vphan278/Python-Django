# Python Django Projects

This repository contains projects and exercises developed while learning Python and the Django web framework.

The goal of these projects was to practice backend web development concepts such as routing, templates, databases, authentication, and RESTful design.

--------------------------------------------------

PROJECTS INCLUDED

Books Authors
A Django project demonstrating relationships between models and database tables.

Dojo Survey
A simple application that collects and displays user survey data.

Login Registration
A project implementing user authentication and session management.

Ninja Gold
A small web game demonstrating session handling and backend logic.

Post Form
An application demonstrating form submission and server-side processing.

Semi Restful TV
A CRUD application demonstrating RESTful routing and database operations.

Session
Examples demonstrating how Django sessions work.

Snack Concessions
A small application simulating an ordering or concession system.

Time Display
A simple project displaying the current date and time using Django templates.

Wall
A message wall application allowing users to post and interact with messages.

Wish
A wishlist application demonstrating user interaction and data storage.

Checkerboard
A small project demonstrating template rendering and dynamic page generation.
